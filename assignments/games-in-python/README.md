# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman word-guessing game using Python strings, loops, conditionals, random selection, and user input.

## 📝 Tasks

### 🛠️ Build the Game Logic

#### Description

Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses from the player
- Track and display the player's incorrect guesses remaining
- End when the word is guessed or the available attempts are exhausted

### 🛠️ Display the Game Progress

#### Description

Show the player's current progress and the final result as the game progresses.

#### Requirements

Completed program should:

- Display the hidden word in `_ _ _` format
- Reveal correctly guessed letters in the appropriate positions
- Display a win message when the word is guessed
- Display a lose message when the attempts are exhausted
